# Code of Conduct

## Purpose

Aurora is built to be usable by both human engineers and machine agents. Collaboration here should be respectful, constructive, and safe for everyone.

## Expected Behavior

- Be respectful and professional.
- Assume good intent and ask clarifying questions.
- Focus on the work and the ideas, not individuals.
- Respect privacy and do not share sensitive or personal information.

## Unacceptable Behavior

- Harassment, discrimination, or hateful conduct.
- Personal attacks, intimidation, or sustained disruption.
- Publishing private information without consent.

## Reporting

If you experience or witness unacceptable behavior:

- For non-sensitive issues, open an issue in [GitHub Issues](https://github.com/JEleniel/aurora/issues).
- If you need a private channel, use [GitHub Security Advisories](https://github.com/JEleniel/aurora/security/advisories) to contact maintainers.
