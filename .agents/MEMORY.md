# Agent Memory

- This file is a local redundant memory ledger for agent tasks in this repository.
- Keep concise, durable facts that aid future work.
- `aurora_cli upgrade` now resolves model home from input, syncs required files from embedded `.github/aurora/{schemas,reference}` assets, and prunes outdated files in `schemas/` and `reference/` before loading models.
- Task 1 complete in `aurora_shared`: `Card::create` now issues registry-based IDs, `Card::write` infers and validates `$schema` from the target path, and `Model::write` stages transactional temp-file writes with rollback on failure.
- Task 2 complete in `aurora_shared`: `Aurora::try_load_for_update` acquires non-blocking per-mission `AuditLog.ndjson` locks via `fs2`, normalizes same-process contention with an in-process registry, and maps lock contention to `AuroraError::ModelLocked` while `Aurora::try_load` remains read-only.
- Task 3 complete in `aurora_shared`: `EditHistory` stores up to 50 reversible snapshot-based `EditCommand`s, `undo`/`redo` reapply model snapshots through `Model::write()`, and failed validation rolls back both in-memory state and on-disk persistence.
- Task 5 complete in the workspace: `tokio` is now a workspace dependency and `aurora_shared` exports a shared background runtime with `spawn_background`, `spawn_blocking_background`, and `block_on_background` helpers for later backup/index work.
- Task 4 complete in `aurora_shared`: `BackupManager` creates timestamped ZIP archives under `aurora/backups/`, excludes the backup directory from archive contents, and supports both editor (`MIS-...`) and MCP (`MCP-MIS-...`) naming via the shared background runtime.
- Task 6 complete in `aurora_shared`: `ConfigBackupManager` creates a one-time `<MISSION_ID>-config-backup.zip` containing only `reference/` and `schemas/`, and `Aurora::write_model_configuration` / `write_view_configuration` abort before any write if that backup cannot be created.
- Task 7 complete in `aurora_shared`: `SvgTemplateDefs` now reads `reference/SVGTemplate.svgz` (with `.svg` fallback), extracts shape and icon IDs from `<defs>`, and is reused by both Aurora icon validation and SVG rendering shape discovery.
- Task 8 complete in `aurora_shared`: `ModelIndex` builds a Tantivy in-memory index over card JSON files, watches the model home with `notify`, and updates search results live on card create/modify/delete events using path-keyed upserts and deletes.
- Task 9 complete in `aurora_editor`: the crate is now a workspace member with a binary entry point, Clap parsing for `--model-home` and `--log`, Tokio runtime initialization, and file-based tracing logs under the user's local data directory.
- Task 10 complete across `aurora_shared` and `aurora_editor`: `ModelHomeSession` acquires audit-log write locks and loads only root missions plus schema state, `ModelIndex` now resolves relative card paths, and `EditorSession` combines both for index-backed lazy card loading with startup-time and lock-refusal tests.
- Task 11 complete in `aurora_editor`: the editor now opens a desktop settings window backed by `SettingsDraft`, persists autosave/theme/font/identity/provider endpoints to the user config file, writes provider API keys to the OS keychain with environment fallback warnings, and reuses log redaction for configured secrets.
- Task 12 complete in `aurora_editor`: startup now defers model-home opening when no config exists, shows a first-run wizard that collects autosave/theme/audit identity, writes the initial config into the OS-standard per-user config directory, and only then opens the locked editor session.
- Task 13 in progress in `aurora_editor`: the desktop app now splits shell composition across `src/app.rs`, `src/app_shell.rs`, and `src/app_settings.rs`, keeps the four-region layout and bounded resize rails from `src/shell.rs`, and resolves theme preference through `src/theme.rs` using the Tao window theme plus `ThemeChanged` events so system/light/dark mode switches apply live without restart.
- Task 13 shell interaction update in `aurora_editor`: the resize rails in `src/app_shell.rs` now expose stable region IDs, are keyboard-focusable with visible focus styling from `src/theme.rs`, and use `src/shell.rs` keyboard mappings (`Arrow` keys plus `Home`/`End`) so sidebar and bottom-panel resizing stays bounded and accessible.
- Task 14 in progress across `aurora_shared` and `aurora_editor`: `aurora_shared::render::focused_graph` now renders a centered card neighborhood (parents above, siblings beside, descendants below) through the shared SVG pipeline and returns clickable hotspots, while `EditorSession` loads `CardRegistry` plus the SVG template from `reference/` and exposes exact inbound-neighbor lookup through `ModelIndex::find_cards_linking_to` for the editor graph view.

- Repository convention: editor/MCP configuration belongs in OS-standard per-user config directories, while logs and other local runtime data belong in OS-standard per-user data directories; nothing outside the model should use system-wide locations.
