# Support

## Community Support

- Ask questions and request help via [GitHub Issues](https://github.com/JEleniel/aurora/issues).

## Bug Reports

- File bugs in [GitHub Issues](https://github.com/JEleniel/aurora/issues).
- Include expected behavior, actual behavior, and minimal repro steps.

## Feature Requests

- Propose enhancements via [GitHub Issues](https://github.com/JEleniel/aurora/issues).
- Describe the intended users and workflows, and how the proposal impacts the Aurora model.
