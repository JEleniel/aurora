# aurora_cli

`aurora_cli` validates Aurora models and renders deterministic Markdown outputs (cards and views).

## What it does

- Validates the Aurora model structure (schemas + invariants).
- Renders Markdown for each card into a stable folder structure.
- Renders a standard set of Mermaid-based view Markdown files.
- Exports a compact, agent-friendly JSON model.

If you are new to Aurora itself (the modeling format), start with the repository
[README](../../README.md) and the design docs index.
