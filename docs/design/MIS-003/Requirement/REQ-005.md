# Requirement: REQ-005 Render View Diagrams

The tooling SHALL render view diagrams (DOT sources plus SVG output) for the canonical view set. Rendering MUST use a Graphviz-compatible DOT renderer (default 'dot') and SHOULD allow overriding the executable via environment configuration (AURORA_DOT_COMMAND).
