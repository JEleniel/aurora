# Requirement: REQ-007 Bump Model Audit Versions

The CLI SHOULD support bumping model audit trail versions (patch, minor, major) with deterministic edits to affected cards and an appended audit history entry. The current aurora_cli surface exposes bump commands but does not yet implement them.
