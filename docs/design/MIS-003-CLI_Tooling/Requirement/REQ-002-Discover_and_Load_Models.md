# REQ-002: **Requirement**

**Name:** Discover and Load Models\

## Description

The tooling SHALL discover one or more Aurora model homes from an input path (file, model-home directory, or ancestor directory) and load all card files under each model home. Discovery is schema-based (presence of Aurora.schema.*), supports a direct child 'aurora/' folder, and bounds directory walking (max depth) for predictable performance.
