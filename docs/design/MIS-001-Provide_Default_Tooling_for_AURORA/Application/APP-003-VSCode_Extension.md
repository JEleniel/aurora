# APP-003: **Application**

**Name:** VSCode Extension\

## Description

A VS Code extension that enables authoring, validation, and visualization of Aurora models within the editor. It provides trust-aware workspace integration, webview-based UI experiences, and (optionally) an MCP server surface for other in-editor tooling.
