# APP-001 (Application)

**Name:** Command Line Tools\

## Description

A deployable command-line application that validates, renders, and manages Aurora models. The CLI is optimized for deterministic, automatable workflows (local scripting and CI), and delegates model semantics (parsing, invariants, rendering) to the shared library.
