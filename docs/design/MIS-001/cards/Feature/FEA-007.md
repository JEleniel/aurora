# Compact Model Export Command

- Type: Feature
- Status: Design

## Description

Provide a `compact` subcommand that writes a compact JSON snapshot of the model to a single file with top-level `{ "cards": [...] }`, where each card is stripped of `audit_trail` and each link is stripped of the `relationship` field. Output is deterministic (stable ordering) for diff-friendly automation.
