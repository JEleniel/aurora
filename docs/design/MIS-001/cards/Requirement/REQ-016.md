# Export Compact Model Snapshot

- Type: Requirement

## Description

The CLI provides a compact export command that emits the model as a single JSON file for machine consumption, removing fields that are not needed for topology/trace analysis (at minimum: audit_trail and links[].relationship), while preserving stable ordering for diff-friendly output.
