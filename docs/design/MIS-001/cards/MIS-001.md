# Enable Deterministic Aurora CLI Tooling

- Type: Mission

## Description

Provide a first-party command-line tool that validates Aurora models and deterministically generates human-friendly documentation and standard views so architects can model systems without hand-drawing diagrams or manually maintaining documentation.
