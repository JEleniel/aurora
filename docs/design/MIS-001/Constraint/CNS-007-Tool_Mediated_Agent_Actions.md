# Constraint: CNS-007 Tool Mediated Agent Actions

Agents MUST NOT execute shell commands or spawn arbitrary OS processes, and MUST NOT write directly to model files. All agent reads and writes MUST be mediated by the editor's model tool surface that enforces validation, invariants, and locking.
