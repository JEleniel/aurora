# Interface: INT-002 Aurora Model Tool MCP Interface

MCP-exposed tool interface for reading and writing Aurora model homes. Tool calls and results are structured JSON and cover the minimum capabilities defined by REQ-028; long-running operations report progress and support cancellation. The MCP tool surface is further described as a set of sub-interfaces: INT-004 (query), INT-005 (edit), and INT-006 (batch).
