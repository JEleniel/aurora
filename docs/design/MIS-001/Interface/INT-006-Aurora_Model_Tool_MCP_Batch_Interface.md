# Interface: INT-006 Aurora Model Tool MCP Batch Interface

Batch MCP tool subset for applying multi-card/link edits as a single all-or-nothing operation (REQ-028) under the exclusive model lock. A failed batch MUST return a clear machine-readable failure report describing which validations failed and what was not applied.
