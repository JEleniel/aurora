# Component (Module): COM-010 Aurora Model Tool API

Constrained model tool surface used by the UI and agents to read and write the model without full materialization. The tool API enforces schema/invariant validation, transactional writes, audit logging, and exclusive-lock requirements. Tool calls and results are structured JSON; the surface may be implemented with MCP.
