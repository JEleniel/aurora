# ADR: ADR-002 Strict json Canonical Storage

Decision: Aurora cards are stored as strict JSON using the .json extension. Rationale: deterministic diffs, wide tool compatibility, and unambiguous machine parsing. Trade-off: no comments; humans must rely on explicit fields and Notes instead.
