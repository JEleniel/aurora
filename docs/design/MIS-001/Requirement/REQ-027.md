# Requirement: REQ-027 Audit Trail and Versioning

All Aurora cards SHALL include an audit_trail with a per-card SemVer version, an optional SHA256 hash (nullable), and a chronological history of created/edited/deleted events including editor identity and RFC3339 timestamps.
