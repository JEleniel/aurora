# Requirement : Configurable Output Folders

aurora_cli writes generated Markdown cards, index README(s), and views to a single configurable output root folder; by default it writes to docs/design/ and creates a per-Mission output folder under docs/design/{MissionId}/ with cards under docs/design/{MissionId}/cards/ and views under docs/design/{MissionId}/views/. aurora_cli creates missing output directories by default and provides a flag to disable directory creation (failing if required output directories do not already exist).
