# Requirement : Accept Model Root Or Mission Path

aurora_cli accepts an input path that resolves to either (a) an Aurora model root folder (an aurora folder containing one or more Mission cards and a schema copy), (b) a parent folder that contains an aurora folder, or (c) a Mission card JSON file. If multiple Mission cards are present in a shared aurora folder, aurora_cli processes each Mission as a separate model rooted at that Mission.
