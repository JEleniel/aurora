# Requirement: REQ-017 Identifiers, Filenames, and Model Layout

Aurora cards SHALL use stable identifiers (e.g., MIS-001) that MUST NOT change once issued. Card files SHALL be named <id>-<Sanitized_Name>.jsjson, where special characters are stripped and spaces are replaced with underscores. Models SHALL follow the Model Home and Mission folder layout conventions so tools can discover, validate, and render deterministically.
