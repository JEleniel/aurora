# Requirement : Generate Card Index README

aurora_cli generates one index README per Mission, grouped by card type starting with that Mission and linking to every generated Markdown card using the card name as link text. When multiple Missions are processed in a single run, aurora_cli also generates an aggregate index README that links to each per-Mission index.
